# ASTROGUIDE-
Учебный программный продукт, разрабатываемый в рамках учебного проектирования. Приложение предназначено для помощи любителям астрономии и космоса в планировании наблюдений за звездным небом.

## Структура проекта

```text
sky-map/
├── pyproject.toml               # зависимости и метаданные проекта
├── .gitignore                   # что не коммитим (кэш, venv, секреты)
├── README.md                    # этот файл
│
├── sky_map/                     # весь Python-код приложения
│   ├── __init__.py
│   │
│   ├── astro/                   # 👤 Петренко — астрономия и данные
│   │   ├── __init__.py
│   │   ├── transforms.py        # RA/Dec ↔ Alt/Az ↔ xyz (математика)
│   │   ├── positions.py         # положения Солнца, Луны, планет (Astropy)
│   │   ├── constants.py         # дефолты: координаты, список планет, лимиты
│   │   └── data_prep.py         # разовый скрипт: готовит звёзды/созвездия
│   │
│   ├── viz/                     # 👤 Лавров — визуализация сферы в Plotly
│   │   ├── __init__.py
│   │   ├── style.py             # читает design_tokens.json, размеры/цвета
│   │   ├── layers.py            # по одной функции на слой
│   │   └── figure.py            # собирает всё в go.Figure
│   │
│   └── app/                     # 👤 Вокуев — Dash: каркас, callbacks, деплой
│       ├── __init__.py
│       ├── app.py               # create_app() — точка входа
│       ├── layout.py            # вёрстка страницы: график, слайдер, инпуты
│       ├── callbacks.py         # реакция на слайдер / координаты / «Сейчас»
│       └── data_loader.py       # читает assets/data/* один раз при старте
│
├── assets/                      # 👤 Перевозник — дизайн и данные
│   ├── design_tokens.json       # единая точка правды по цветам/размерам
│   ├── css/
│   │   └── style.css            # стили панели, инпутов, кнопок
│   ├── images/                  # иконки, логотип, favicon
│   └── data/                    # сгенерированные данные (см. ниже)
│       ├── stars.parquet        # звёзды (ra, dec, mag) — генерит Петренко
│       ├── constellations_lines.json   # линии созвездий — генерит Петренко
│       └── constellations_labels.json  # подписи созвездий — генерит Петренко
│
└── tests/                       # у каждого — свои тесты
    ├── test_transforms.py       # Петренко
    ├── test_positions.py        # Петренко
    ├── test_layers.py           # Лавров
    └── test_callbacks.py        # Вокуев
```
